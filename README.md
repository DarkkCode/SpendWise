# SpendWise 
**Personal Finance & Expense Tracker**

A Hybrid Mobile Application built for the Final Project using React Native and Firebase.

###  Features
* **Authentication:** Secure Login & Register via Firebase Auth.
* **Real-time Database:** Transactions synced with Google Firestore.
* **Data Isolation:** Every user sees only their own expenses.
* **Budgeting:** Interactive monthly budget limits saved to the cloud.
* **CRUD Operations:** Add, View, Edit, and Delete transactions.

###  Tech Stack
* **Framework:** React Native (Expo)
* **Backend:** Firebase (Auth & Firestore)
* **Navigation:** React Navigation (Tabs & Stack)
* **State Management:** React Context API

###  How to Run
1. Clone this repo: `git clone https://github.com/DarkkCode/SpendWise.git`
2. Run `npm install`
3. Run `npx expo prebuild`
4. Run `npx expo run:android`
